PUT THE WEBSITE VIDEO IN THIS FOLDER
====================================

1. Save / copy your video here.
2. Name it exactly:   VID.mp4

   Folder path:  assets/video/VID.mp4
   Full example: /home/user/assets/video/VID.mp4

That is the only step — the site already points at this file, so the play
button on the home page ("Watch our film") will start working as soon as the
file is here.

Notes
-----
* The file name is CASE-SENSITIVE on the live server. Save it as "VID.mp4"
  (upper-case VID, lower-case .mp4) or the browser will not find it.
* MP4 / H.264 is the safe format — it plays in Chrome, Edge, Safari, Firefox,
  Android and iPhone. (A .MOV from an iPhone renamed to .mp4 usually will NOT
  play; export/convert it to MP4 first.)
* Keep it web-sized: 720p or 1080p, and ideally under ~50 MB so the page stays
  quick. A free converter (e.g. HandBrake) can do this.
* This file (README.txt) is not linked from the website and can be deleted
  once the video is in place.
